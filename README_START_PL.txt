APEX CONTEXT ENGINE 1.0 — SZYBKI START (WINDOWS 64-BIT)

CO ROBI PROGRAM
Program pobiera pełny, bieżący zestaw kursów z podanej strony wydarzenia
Betclic, zachowuje pochodzenie i rozliczenie rekordów, a następnie buduje
deterministyczny raport kontekstu rynku. Nie zawiera AI i nie stawia zakładów.

WERSJA PORTABLE
1. Rozpakuj cały plik APEX_Context_Engine_Portable_Win64.zip.
2. Nie przenoś samego pliku EXE poza rozpakowany katalog.
3. Uruchom APEX_Context_Engine.exe.

INSTALATOR
Uruchom APEX_Context_Engine_Setup_Win64.exe i przejdź przez instalację.
Instalator tworzy skrót „APEX Context Engine” w menu Start i na pulpicie.

UŻYCIE
1. Wklej adres konkretnego wydarzenia Betclic.
2. Kliknij „POBIERZ PEŁNE KURSY”.
3. Po wyniku GOTOWE możesz skopiować pakiet źródłowy lub kliknąć
   „ZBUDUJ KONTEKST RYNKU”.
4. Zamykaj aplikację zwykłym przyciskiem X.

PLIKI WYNIKOWE
Wyniki i diagnostyka są zapisywane w:
%LOCALAPPDATA%\APEX Context Engine

WYMAGANIA I UWAGI
- Windows 10/11 x64 i połączenie z Internetem.
- Python nie jest wymagany.
- Oficjalny Chromium Playwright jest dołączony do programu.
- Używaj wydarzenia przedmeczowego. Mecz trwający, zakończony lub przełożony
  zostanie bezpiecznie zablokowany.
- Jeżeli Betclic pokaże stronę ochronną/cookies albo antywirus ostrzeże o
  niepodpisanym wydawcy, zamknij okno, sprawdź połączenie i uruchom ponownie.
