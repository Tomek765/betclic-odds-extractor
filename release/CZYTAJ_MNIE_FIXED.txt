APEX CONTEXT ENGINE - FIXED (build APEX_CONTEXT_ENGINE_FIXED_20261002_FAST4)

ZAWSZE NAJNOWSZA WERSJA
Instaluj tylko paczke z najnowszym znacznikiem (np. FAST4). Stare paczki
usun - instalator je wskaze i moze przeniesc do Kosza. Wersje widac w oknie
programu (WERSJA: ...) i w tescie na zywo (wiersz WERSJA).

INSTALACJA (Windows 10/11 x64)
1. Rozpakuj caly ZIP (np. do Pobrane). Nie uruchamiaj jako Administrator.
2. Wejdz do folderu APEX_Context_Engine_FAST4 (nazwa zawiera wersje).
3. Kliknij dwukrotnie INSTALUJ.cmd.
   - instalator pokaze wersje zainstalowana i nowa; starszej wersji na
     miejsce nowszej NIE zainstaluje
   - wypisze stare paczki APEX z Pobranych/Pulpitu i zapyta, czy przeniesc
     je do Kosza (T + Enter)
   - program zostanie skopiowany do
     %LOCALAPPDATA%\Programs\APEX_Context_Engine_FIXED_2026-09-27
   - na pulpicie pojawi sie skrot "APEX Context Engine - FIXED"
   - program uruchomi sie z tego skrotu, a instalator sprawdzi, ze dziala
     nowy build (tytul okna zawiera APEX_CONTEXT_ENGINE_FIXED_20261002_FAST4)
   - wynik zapisuje sie w INSTALL_REPORT.txt w folderze programu
4. Jesli Windows SmartScreen pokaze "System Windows ochronil ten komputer",
   wybierz "Wiecej informacji" -> "Uruchom mimo to" (plik nie jest podpisany).

Mozna tez uruchomic APEX_Context_Engine.exe bezposrednio z rozpakowanego
folderu (wersja portable) - bez instalacji.

STARA WERSJA (bez FIXED)
Nie jest zmieniana ani usuwana. Stary skrot "APEX Context Engine" nadal
uruchamia poprzedni program. Oba programy zapisuja wyniki w
%LOCALAPPDATA%\APEX Context Engine (kazdy przebieg w osobnych plikach).

TEST NA ZYWO
Kliknij dwukrotnie TEST_NA_ZYWO.cmd (w rozpakowanym folderze albo w folderze
programu), wklej link do meczu przed rozpoczeciem i poczekaj 1-3 minuty.
Test uruchamia program ze swojego folderu i sprawdza jego wersje.
Wynik PASS oznacza: ekstrakcja poprawna, pakiet kursow i kontekst to dwa
rozne, czyste produkty. Wiersz POMINIETE CELOWO to nie sa bledy - to oferty
bez potwierdzonych zasad rozliczenia Betclic.
PASS Z OSTRZEZENIAMI oznacza: program dziala poprawnie, ale np. Betclic nie
pokazal jednej zakladki (PUSTE ZAKLADKI) - reszta danych jest kompletna.
FAIL oznacza brak strukturalny albo ZLA WERSJA PROGRAMU.
